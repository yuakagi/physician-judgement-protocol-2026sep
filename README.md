# Blinded discrimination study: protocol and analysis plan

This repository holds the pre-specified protocol of a blinded study in which clinicians are
asked to distinguish a patient's real clinical course from a course generated by the Watcher
simulator (https://github.com/yuakagi/Watcher). The protocol was fixed before any rating was
collected.

| File | Content |
|---|---|
| `PROTOCOL.md` | Hypothesis, design, case sampling, rater eligibility and inclusion, rating period, instrument, blinding, primary measure, decision rule, secondary analyses and scope of the conclusions, structured after the OSF preregistration template. Version 1.0, fixed 24 September 2026 |
| `CHANGELOG.md` | Every change to the protocol after version 1.0, with its date and whether it was made before or after results were seen |
| `power_simulation.py` | Reproduces the planning power table using synthetic outcomes and the specified case-level bootstrap; requires NumPy 2.4.6 |

## Archiving

The version cited in the manuscript will be a tagged release of this repository archived on
Zenodo. Its DOI will be given in the manuscript's Data Availability statement. The analysis code
will be released with the manuscript.

## Ethics

Approved by the Research Ethics Committee of the University of Tokyo (2023367NI). All raters are
co-authors of the manuscript; no external participant is involved. No patient data leave the
institution.
